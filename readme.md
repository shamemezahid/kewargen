## Kewargen / QR Gen

A simple, browser-based QR code generator. Open `kewargen.html` in a web browser, enter your information, and click **Generate QR Code**.

### Features

- Create QR codes for:
  - Links and text
  - E-mail, phone calls, and SMS
  - vCards
  - WhatsApp messages
  - Wi-Fi networks
  - PDF, app, image, video, and social media URLs
  - Calendar events
  - 2D barcode data
- Choose the QR code shape: square, rounded, circle, or lines.
- Change the foreground and background colors.
- Add an optional logo image.
- Download the QR code as SVG or PNG.
- Responsive layout for desktop and mobile screens.

### How to Use

1. Open `kewargen.html` in a browser.
2. Select a data type.
3. Fill in the fields.
4. Choose the shape and colors.
5. Optionally add a logo.
6. Click **Generate QR Code**.
7. Download the result as SVG or PNG.

### Note

If you add a logo, download the PNG version. The logo is shown in the preview and included in the PNG, but it is not included in the SVG download.

No installation or build process is required.
